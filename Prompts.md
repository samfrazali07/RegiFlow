
# Prompts & Engineering Log – RegiFlow

**Project:** RegiFlow – Smart Registration Wizard  
**Assignment:** Prodesk IT Sprint 07 – Phase 3: Core Engineering  
**Technology Stack:** React, Vite, JavaScript, React Hook Form, Zod, CSS3, Lucide React

---

## 1. AI Tools Used

AI Coding Assistant (Workspace Agent) was used as a learning and development assistant throughout the project.

The primary purpose of using AI was to understand React concepts, explore different implementation approaches, improve problem-solving skills, and receive guidance while debugging technical issues.

AI assistance was used for:
- Understanding React component architecture and conditional rendering.
- Learning form handling and validation using React Hook Form and Zod.
- Exploring JavaScript-based implementation approaches.
- Understanding CSS styling and responsive UI design.
- Debugging development errors and reviewing implementation logic.
- Learning how to test and verify application functionality.

---

## 2. Development Prompt

The following prompt was used to guide the development of the RegiFlow application:

"Help me understand and develop a modern, responsive three-step registration wizard using React, Vite, and JavaScript.

Guide me through the implementation step by step and explain the purpose of important components, hooks, and functions so I can improve my frontend development skills.

The application should include:

1. A Personal Information step with first name, last name, and date of birth.
2. An Account Details step with email, password, and confirm password fields.
3. A Review and Submit step displaying the entered information before final submission.
4. Form validation using React Hook Form and Zod.
5. Password confirmation validation and independent show/hide password functionality.
6. A dynamic progress indicator showing the current wizard step.
7. Navigation between steps while preserving previously entered form data.
8. A success screen with a Start Again button to reset the registration process.

Use reusable React components, clean JavaScript code, and pure CSS3 for styling. Avoid unnecessary libraries and keep the implementation beginner-friendly.

Whenever an error occurs, help me understand its root cause and explain the solution rather than simply replacing the code."

---

## 3. Learning & Development Process

During development, AI assistance was used to understand the existing Vite project structure and adapt it to the required JavaScript-based architecture.

The development process focused on:
- Creating reusable components for each registration step.
- Understanding parent-level form state management.
- Implementing conditional rendering without React Router.
- Applying field-level validation and displaying inline error messages.
- Maintaining form values when navigating between steps.
- Improving the UI with responsive layouts and consistent styling.
- Understanding how to test form behavior and handle edge cases.

---

## 4. Errors & Debugging

AI assistance helped investigate and understand several development issues, including:

The suggested solutions were evaluated through implementation and testing to ensure the application behaved as expected.
